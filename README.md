# RoboLab Management System — Version 1

A responsive Robotics Lab Management frontend built using only concepts appropriate for the current learning stage:

- HTML5
- CSS3
- Flexbox / responsive CSS
- Bootstrap 5
- Basic JavaScript functions
- HTML form validation

## Pages

- Dashboard
- Projects
- Inventory
- Team
- Equipment Requests

## Current limitation

This version intentionally uses a static dataset. Dynamic add/edit/delete/search/filter functionality requires DOM manipulation and event handling, which will be added in Version 2 after learning those topics.
